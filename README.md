## 2. Расчет годовой стоимости (Annual Cost Projection)

> **Обоснование объема:** Объём принят равным 100 000 обращений в год, что соответствует средней нагрузке первой линии службы поддержки локального B2C-сервиса.

Расчет выполнен для модели **Claude 3 Opus** (по тарифам: $15.00 / 1M input токенов, $75.00 / 1M output токенов) и для сравнения приведен вариант на **Claude 3.5 Sonnet** ($3.00 / $15.00) и **Claude 3 Haiku** ($0.25 / $1.25):

## 3. Выбор модели для Kazakh-Language Support Queue

Для службы поддержки на казахском языке рекомендуется использовать **Claude 3.5 Sonnet** (или **Claude 3 Haiku** для простых сценариев FAQ).

**Обоснование:**  
Из-за особенностей токенизации (BPE) идентичный по смыслу контекст на казахском языке требует в **2.19 раза больше входных** и в **1.40 раза больше выходных токенов**, чем на английском. Использование топовой модели (Opus) обойдется в $10 500 в год для казахской очереди против $7 380 для английской при аналогичном объеме задач. Модель Sonnet 3.5 обеспечивает высокое качество понимания флективного казахского языка при стоимости в 5 раз ниже ($2 100/год), а Haiku полностью перекрывает базовые ответы поддержки всего за $175/год.

## 4. Рычаг снижения затрат (Cost-Reduction Lever)

В данной лабораторной работе не использовалось **кэширование промптов (Prompt Caching)**, которое позволяет сохранять повторяющийся системный промпт (124 токена) и префиксы частых вопросов, снижая стоимость входных токенов на 90%.
